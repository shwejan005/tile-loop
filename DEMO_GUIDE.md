# TileLoop — demo guide

Open <http://127.0.0.1:3000/demo>. This sample is interactive and does not require sign-in.

1. Show the L-shaped room preview, obstacle, floor opening, and doorway marker.
2. In **Room outline**, choose custom, upload a PNG/JPEG/WebP plan, click **Trace room outline**, add boundary points, then apply. The image stays in the browser; only the measured outline is saved.
3. Try diagonal, then herringbone (requires the demo’s 2:1 tile format).
4. Switch between **2D** and **3D**. Select a piece to show its ID and dimensions.
5. Review the cut schedule, offcut candidates, and carton estimate.
6. Point out that the sample carton size is illustrative. The layout estimate is heuristic and needs installer review.

The public demo does not save. To save plans or record actual installation outcomes, create an account and open a project.
