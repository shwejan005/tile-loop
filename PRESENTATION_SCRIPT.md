# TileLoop — short presentation

Hi, I’m Shwejan. TileLoop helps tile installers plan a job before they start cutting.

You can describe the room, add obstacles and openings, choose a tile pattern, and set grout and saw kerf. TileLoop then shows numbered cuts in 2D and 3D, estimates material, and records the assumptions behind the plan.

After installation, you can record actual tile use, breakage, time, and installer feedback. That gives us real project data to evaluate and improve the estimates.

The demo uses sample data. Carton size must be verified, and estimates still need installer review. TileLoop’s goal is to make planning clearer—and learn from what happens on site.
